# Отчёт по плотности волн и балансу — Спринт 16.1–16.2

**Базовая точка (До):** Спринт 12.1 (`Docs/Balance/Sprint12_1_BalanceReport.md`)  
**Инструмент моделирования:** `BalanceCurveSimulator` (`ProjectB → Debug → Balance Curve Simulator`)

---

## 1. Изменения `WaveConfig` и `BossData`

| Параметр | 12.1 (До) | 16.1 (После) | Эффект |
|---|---:|---:|---|
| `hpLinearPerWave` | 0.100 | **0.085** | Плавнее HP обычных мобов (`×15.80 → ×11.38` на W100) |
| `hpQuadraticPerWave` | 0.0005 | **0.0002** | Убрана «HP-губка» на W50–W100 |
| `spawnDelay` (на насыщении W13+) | 0.50 с | **0.50 → 0.16 с** | Темп выхода толпы ускоряется к W40 |
| `waveOverlapThreshold` | 0% (полная зачистка) | **30%** (после насыщения) | Новая волна стартует при `≤ 30%` живых |
| `eliteChancePerWave` / `maxEliteChance` | 5% / 25% | **2.5% / 35%** | Сложность смещена в элит на средних/высоких волнах |
| `scalePackSizeWithWave` (`Slime`, `Skeleton`, `Splitter`) | — | **+1..+2 на W20/W40+** | Плотнее стаи на поздних волнах |
| `coinLinearPerWave` / `maxCoinMultiplier` | 0.015 / 2.5 | **0.007 / 1.65** | Компенсация более быстрого темпа волн |
| `CorridorHorde` | — | **с W19, каждые ~10 волн** | 12 с поток слабых (`0.55× HP`) мобов с одного направления |
| Боссы (база HP: Golem / Necro / Lich / Demon) | 950 / 1000 / 1400 / 1900 | **1100 / 1250 / 1800 / 2600** | Итоговый HP боссов сохранён (`3 471 / 7 057 / 15 093 / 29 576`) |

## 2. Итоговые метрики (`BalanceCurveSimulator`)

- **Первые 5 забегов (Pure F2P):** `398` монет → **4 мета-покупки** (цель: 3–5).
- **50% меты / 100% меты (Pure F2P, без дейли):** **7.3 ч** / **37.7 ч** (цель: 5–14 ч / 35–80 ч).
- **50% меты / 100% меты (+ ~300/ч дейли):** **6.6 ч** / **35.4 ч**.
- **Волны-стены DPS-модели:** Run 1 `W13` → Early `W20` → Mid `W32` → Late-Mid `W60` → Endgame `Clears W100`.
- **LevelUp на W30+:** минимальный интервал **15.6 с** даже при `×3.0 XP` (цель: ≥ 15 с).
