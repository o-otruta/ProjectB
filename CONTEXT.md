# Project Context: «ProjectB»

> Актуально на коммит `66073eb` (Спринты 1–11, 13, 14.1 и 15.1–15.4 завершены). Детальный аудит и ТЗ спринтов — [AUDIT.md](./AUDIT.md), роадмап и открытые задачи — [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md).

## Документация и Концепт

* **Рабочее название:** ProjectB (кандидаты: **Swarm Hero**, **Swarm Hero: Voxel Survivor**)
* **Жанр:** Roguelike Survivor + Auto-battler (вдохновлено Megabonk)
* **Платформа:** сначала Web (Poki или CrazyGames, + демо на itch.io), затем Android (Google Play), далее Galaxy Store / TapTap / Steam (Amazon — бэклог)
* **Движок:** Unity 6, URP
* **Графика:** Voxel Art (стилизованные воксельные 3D-модели)
* **Ориентация:** Адаптивная (портрет `9:16` — основной на телефонах; ландшафт — Web и планшеты; управляется `OrientationPolicy`)
* **Архитектура:** Singleplayer only
* **Целевая сессия:** первые забеги 2–5 минут (волны 5–12); прокачанные забеги — до волны 100+

## Соглашения и Правила разработки (Conventions)

### История коммитов (Conventional Commits)
Все коммиты в проекте должны строго следовать стандарту **Conventional Commits**.
Формат: `<type>[optional scope]: <description>`

### Зафиксированные дизайн-решения (обязательно соблюдать)
1. **Без потолка `maxLevel` у способностей** — бесконечная прокачка; вместо «эволюции» работают пороги Overdrive (Lv 10 / 20 / 30+).
2. **Синергии — чистые реактивные механики** (в духе *Divinity: Original Sin 2*), без плоских стат-баффов и без карточек в пуле LevelUp. Открываются узлами Дерева Созвездий и активируются в забеге автоматически при сборе пары способностей.
3. **Волны знакомства без UI-подсказок** — в волне дебюта нового врага ~50% мобов нового типа, никаких баннеров.
4. **Иконки карточек `16×16`** пока остаются; унификация всех UI-иконок через 3D-рендер в Blender — в отложенном арт-полише. Иконки нижних вкладок меню перерисованы в Спринте 13 (процедурный пиксель-арт).
5. **Дерево Созвездий радиальное** — свободное 360°-панорамирование и зум, управление одной рукой.
6. **Без пунктирного кольца под элитами** — элиты выделяются rim-подсветкой шейдера `VoxelLit`.
7. **Биомы, боевой AdMob SDK и релизный `.aab`** отложены в Pre-Release / Post-Launch.
8. **Адаптивная ориентация вместо строгого Portrait Only:** портрет — основной режим на телефонах (сохраняется нативный формат TikTok/Shorts), ландшафт — для Web и планшетов; разрешённые ориентации задаёт `OrientationPolicy` билд-профиля.
9. **Совместимость сохранений не нужна до релиза 1.0:** старые сейвы не мигрируем; после первого публичного релиза правило снимается (`SaveManager.Migrate`, Спринт 17.6).

## 1. Концепция

Ты — воксельный герой с автоатакой. Волны врагов идут **на тебя** со всех сторон. Ты бегаешь по процедурно-генерируемой арене (намного больше экрана, камера следует за героем), собираешь XP-кристаллы и при каждом levelup выбираешь улучшение из 2 бесплатных карточек (или 3-й случайной за рекламу). Герой автоматически использует **активные и пассивные способности** (орбитальные мечи, турели, ауры, снаряды, дракончики, торнадо, пассивные баффы), а собранные пары способностей запускают **реактивные синергии** (поджог ядовитой лужи, паровой взрыв, лазерный забор между турелями). Между забегами — перманентная прокачка за монеты, **Дерево Созвездий** за Осколки Боссов и разблокировка контента через ачивки. Стиль — 3D survivor а-ля Megabonk, но на мобилу с воксельной графикой.

**Ключевое отличие от чистого TD:** способности привязаны к герою — они летают/бегают вокруг него или работают как ауры. Игрок управляет только движением героя (+ кнопка ульты). Атака автоматическая (автобатлер). Это создаёт визуально хаотичный и залипательный геймплей, идеальный для коротких видео.

### Фирменные столпы
1. **Реактивные синергии** — способности физически взаимодействуют друг с другом на поле боя.
2. **Бесконечная прокачка с Overdrive** — вехи Lv 10 / 20 / 30+ визуально и системно усиливают способность.
3. **Драматургия забега** — волны знакомства, события волн (Swarm Rush, Gold Goblin, Blood Moon, Elite Ambush), комбо-счётчик, 4 уникальных босса.
4. **Длинная мета** — 8 мета-апгрейдов, радиальное Дерево Созвездий с Keystone-перками, 6 героев и 27 ачивок с разблокировками.

## 3. Core Loop (внутри забега)

```
Волна врагов → Герой двигается + способности автоатакуют → Враги дропают XP + монеты → Levelup → Выбор карточки (2 бесплатные + 1 за рекламу) → Новая способность / модификатор / бафф → Собрана пара → Реактивная синергия → Следующая волна
```

### 3.1 Управление и жизненный цикл (Portrait + Adaptive Landscape)
- **Виртуальный джойстик** (нижняя часть экрана в портрете; в ландшафте — плавающий при Touch, клавиатура/геймпад добавляются в 14.3) — движение героя
- **Всё остальное автоматическое** — атака героя (стартовое оружие) + способности
- **Кнопка ульты** (правый нижний угол) — активная способность героя (перезарядка, учитывает CDR)
- **Пауза и фон:** при сворачивании (`OnApplicationPause`/`OnApplicationFocus`) в состоянии `Playing` игра автоматически ставится на паузу и записывает чекпоинт забега (`RecordRunProgressToSave` + `SaveData.runInProgress`); выход в меню с подтверждением (`AbandonRunAndGoToMenu`) также сохраняет монеты и прогресс.

Арена **больше экрана**, камера top-down 45° следует за героем. Арена процедурно генерируется по seed с препятствиями. Враги спавнятся за пределами видимой области.

```
┌───────────────┐
│ HP / XP / Lv  │  ← верхняя полоска + волна, монеты, пауза
│ [слоты 3+3..] │  ← иконки активных/пассивных способностей
│   [Combo x30] │
│     Враги     │
│    ↓  ↓  ↓    │
│   ● Герой ●   │  ← способности вокруг героя
│    ↑  ↑  ↑    │
│     Враги     │
│               │
│        [Ульта]│
│    [🕹️]      │  ← джойстик по центру
└───────────────┘
```

### 3.2 Система уровней и карточек (XP → Levelup)
Враги дропают **XP-кристаллы** (притягиваются магнитом). Формула XP для следующего уровня: `baseXP * (level ^ 1.12)` (`baseXP = 9`, степень настраивается в `HeroExperience`). При наборе достаточного XP → **levelup** (геймплей на паузе):
- Показываются **2 бесплатные карточки** + **3-я случайная карточка за просмотр рекламы** (без буста редкости, чистый рандом; через `AdManager`)
- **Реролл:** базовая настройка в `RunRulesConfig` (`freeRerollsPerRun = 1` + узел Созвездия `+1 Free Reroll`), далее — реролл за рекламу
- Редкости карточек (`Common 50 / Rare 30 / Epic 15 / Legendary 5`) влияют на вес выпадения и цвет рамки
- Новые способности выпадают, только пока есть свободный слот нужного типа
- Статы забега (`HeroRuntimeStats`):
  - **Global Damage** комбинируется с мета-апгрейдами урона (`HeroDamage`, `AbilityDamage`) **мультипликативно**: `(1 + metaBonus/100) * GlobalDamageMultiplier`.
  - **Броня (Armor)** снижает входящий урон с убывающей отдачей: `damage * 100 / (100 + armor)` (минимум 1 урона).
  - Также: Crit Chance / Crit Multiplier, Cooldown Reduction (оружие, способности и ульта), Global Area, регенерация, бонус к монетам/XP.
- **Защита героя:** после получения урона — короткие i-frames (`RunRulesConfig.postHitInvulnerabilityDuration = 0.18s`, расширяются Созвездием), вспышка модели и красная виньетка на HUD.

**Типы карточек (`Resources/CardCatalog.asset`, 96 шт.):**
| Тип | Класс | Кол-во | Примеры |
|---|---|---|---|
| Новая способность | `AbilityCardData` | 27 | «+Fireball», «+Chain Lightning» |
| Улучшение способности | `AbilityModifierCardData` | 63 | «Chain Lightning: +6 Damage», «Spire: Wider Blast» |
| Пассивный бафф героя | `StatUpgradeCardData` | 3 | Global Damage, Max HP, Magnet Radius |
| Улучшение оружия | `WeaponUpgradeCardData` | 3 | `Multishot` (+1 снаряд веером), `FireRate` (+20%), `Power` (+30% урона) |

Карточек синергий в пуле нет: синергии работают автоматически (см. 3.4), легаси `SynergyCardData` удалены.

### 3.3 Способности (Активные и Пассивные)
Способности — ядро геймплея. Бывают активными (наносят урон, спавнят объекты) и пассивными (улучшают статы).

**Слоты:** базово **3 активных + 3 пассивных**, расширяются до **6+6** ачивками и Keystone-перками Созвездия (`AbilitySlotService` + `IAbilitySlotBonusProvider`).

**Типы поведения активных способностей:**
- **Орбитальные** — крутятся вокруг героя (мечи, щиты)
- **Стрелковые (Projectile)** — выстреливают в ближайших врагов (снаряды, фаерболы, чакрам, бумеранг)
- **Следующие (Minions)** — летят за героем и атакуют сами (дракончики)
- **Аура** — эффект вокруг героя (замедление, притяжение, урон)
- **Стационарные / зоны** — объекты на земле живут N секунд (турели, лужи, торнадо, приманка)

**Overdrive (вместо эволюции, без `maxLevel`):**
- **Lv 10 — OVERDRIVE:** `+15%` масштаб, усиленная эмиссия, системный бонус (`+20%` скорости/дальности/радиуса), золотой текст.
- **Lv 20 — AWAKENED:** `+25%` масштаб, шлейф, `+1` снаряд/объект/прыжок.
- **Lv 30+ — MYTHIC** (каждые +10 уровней): мягкий визуальный импульс и рост урона.

### 3.4 Реактивные синергии
Синергия открывается **навсегда** узлом в Дереве Созвездий (`ISynergyUnlockProvider` → `TalentTreeManager`) и **автоматически активируется в забеге**, как только у героя собраны обе способности пары (`SynergyActivatedEvent`, вспышка `SYNERGY: …!`). Не тратит levelup и не накручивает уровни.

### 3.5 Комбо
`RunComboTracker` (настраивается через `ComboConfig`): серия убийств с окном `3s`. Вехи `x15 / x30 / x50 / x100` дают временный бонус `+10 / +15 / +20 / +30%` к XP и монетам; счётчик на HUD (`ComboHudUI`).

### 3.6 Волны и лимиты
- Бесконечные волны с нарастающей сложностью: старт `6` врагов, `×1.2` за волну, максимум `50` за волну, таймаут волны `30s`.
- **Глобальный потолок врагов и пикапов:** `WaveConfig.maxActiveEnemies = 300` с «долгом волны» (если активных врагов ≥ 300, спавн откладывается до освобождения слотов); при превышении `PickupConfig.maxActiveXpCrystals = 300` / `maxActiveCoins = 300` новые пикапы сливаются в ближайшие с визуальным укрупнением.
- **Раздельный скейлинг** HP (`+10%` линейно + `0.05%` квадратично за волну), урона (`+5%` за волну, потолок `×6`) и монет (`+1.5%` за волну, потолок `×2.5`) в `WaveConfig`.
- **Фазовый ввод врагов** + **волны знакомства** (~50% новых мобов в волне дебюта, без UI-подсказок).
- **Элиты** с волны 10 (шанс `+5%` за волну, максимум `25%`).
- **Каждые 5 волн — мини-босс** (`×5 HP`, `×2` урон, `×1.85` размер).
- **Каждые 25 волн — босс:** W25 Stone Golem → W50 Necromancer → W75 Frost Lich → W100 Demon Lord (далее по циклу). Во время босса обычные враги не спавнятся.
- **События волн** (`WaveEventManager`): с волны 4, каждые 3–4 обычные волны (не на Intro/Boss волнах), баннер на HUD:

| Событие | Длительность | Механика | Награда |
|---|---|---|---|
| **Swarm Rush** | 18с | Кольцо из 24–32 скелетов вокруг героя (`r = 15м`) | Момент для ульты, бочки и комбо |
| **Gold Goblin** | 22с | Убегающий золотой гоблин с золотой стрелкой компаса | Монеты за каждое попадание + 40–80 монет при смерти |
| **Blood Moon** | 25с | Красный свет, враги `+20%` скорости | `×2 XP` и `×2` монет |
| **Elite Ambush** | До зачистки | 3 элиты разных архетипов треугольником | `+50` монет за последнего |

### 3.7 Объекты арены
- **Арена:** `500×500`, seed-генерация, 180–190 препятствий без наложений (`Physics.CheckSphere`), 50 000 травинок + 1 400–1 800 пропов через chunk-culled GPU Instancing.
- **Взрывные бочки** (`ExplosiveBarrel`): 8–12 на старте, AoE-взрыв от любого урона; автоатака целится в бочку, только если рядом есть враги.
- **Challenge Shrine:** победи 6 элит → `+100` монет и `+2` Осколка Босса.
- **Vacuum Magnet:** притягивает все кристаллы и монеты на арене; падает с мини-босса (25%) и босса (100%).
- **Живая арена:** каждые 12 волн — 2–3 новые бочки и Алтарь в `22–45м` от героя.
- **Multi-POI компас:** до 3 стрелок одновременно — Алтарь (алая), Vacuum Magnet (голубая), Gold Goblin (золотая).

### 3.8 Секретные предметы на арене
На арене с **редким шансом** (`SecretConfig`: базово `10%` за забег, `+20%` от узла Созвездий `Secret & Shrine`; макс 1 за забег, минимум `28м` от центра) появляется **секретный предмет**. Он даёт бонус внутри забега и нужен для ачивок. Компас его **не показывает** — секрет находят, исследуя арену (заметен по световому столбу-маяку и частицам).

| Предмет | Эффект в забеге | Ачивка |
|---|---|---|
| Сундук с монетами | Большой бонус монет | `Treasure Hunter` — найти 2 сундука (кумулятивно) → `Golden Idol` |
| Древний свиток | Бесплатный levelup | `Ancient Scholar` — найти 1 свиток |
| Загадочный кристалл | Случайная редкая+ способность | `Secret Collector` — найти 1 кристалл |

## 4. Meta Loop (между забегами)

```
Забег → Монеты → Мета-апгрейды / внутренний круг Созвездий → Следующий забег (сильнее)
      → Осколки Боссов → Дерево Созвездий (статы, синергии, Keystone-перки, слоты)
      → Выполнил условие ачивки → Разблокировал героя / способность / слот
```

### 4.1 Ресурсы
| Ресурс | Источник | Назначение |
|---|---|---|
| XP-кристаллы | Дроп с врагов (в забеге) | Levelup внутри забега → выбор карточки |

### 4.5 Ежедневный бонус
Отдельный экран в главном меню (наравне с «Прокачка» и «Ачивки»). Мотивирует заходить каждый день.

- **7-дневный цикл** наград: монеты `100 / 200 / 300 / 400 / 500 / 600 / 700`
- После 7-го дня — новый цикл с наградами `×1.2` (накапливается до 5 циклов)
- Награду можно **удвоить за рекламу** (rewarded ad)
- Пропуск дня — не сбрасывает прогресс цикла, но день не засчитывается; защита от перевода часов
- Тип награды «способность» (`abilityId`) поддержан кодом, но в текущем конфиге не используется
- Визуально: 7 ячеек, текущий день подсвечен, собранные — с галочкой, будущие — затемнены

### 4.6 Главное меню
Нижнее меню с вкладками: «Играть» (выбор героя + 3D-превью), «Прокачка» (мета-апгрейды + вход в Дерево Созвездий), «Способности» (коллекция способностей и синергий со статусом разблокировки), «Ачивки» (бейдж новых), «Бонус» (индикатор доступной награды). Отдельно — попап «Настройки» (громкость музыки/SFX). Баланс монет — в шапке меню, Осколки Боссов — на экране Созвездий.

### 4.7 Экран Game Over
Волна, монеты, Осколки Боссов, убийства, время, лучшее комбо; **Damage Breakdown** (источники урона с прокруткой: иконка, урон, DPS, доля); ачивки, полученные за забег; кнопки «Воскреснуть (реклама)», «x2 монеты (реклама)», «Заново», «В меню».

## 7. Арт-дирекция (Voxel)

### 7.1 Стиль
- **Blender** — основной инструмент для воксельных ассетов (`ArtSources/Blender/*.blend` → `.obj` в `Assets/_VoxelModels/`)
- Визуальный стиль: вдохновение Megabonk (ретро-3D, «игрушечная диорама» с воксельной стилизацией)
- Палитра: яркие, насыщенные цвета (не реализм)
- Размер персонажей: 16–24 воксела в высоту; враги: 8–16 вокселей (читабельность на мобиле)
- Камера: top-down с наклоном 45°, адаптивная ориентация (портрет на телефонах, ландшафт для Web/планшетов)
- Анимация: покадровые `.obj` через `VoxelMeshAnimator` (стоп-моушен) + процедурные покачивания

### 7.2 Почему воксели
- Быстро создавать ассеты (1 персонаж = 1–2 часа)
- Легко анимировать (покадрово или процедурно)
- Низкий poly-count → отличная производительность на мобиле
- Узнаваемый стиль → легко выделиться в сторе
- Хорошо смотрятся на видео (яркие, чёткие)

### 7.3 Технические ограничения
- Текстуры: цветовая палитра (texture atlas), двухматериальная схема `Base_Mat` + `Glow_Mat`
- Шейдер: `ProjectB/VoxelLit` — белый хит-флеш (`_HitFlash` через MaterialPropertyBlock), rim-подсветка элит и боссов (`_RimColor`), мягкое затемнение у основания (`_HeightAO`)
- Пост-обработка: единый URP-профиль `ProjectB_PostFX` (`Bloom`, `Vignette`, `ColorAdjustments`; `Mobile_RPAsset ShadowDistance = 30`)
- Иконки: карточки — `16×16` пиксель-арт (временно), вкладки меню и иконки UI-кита — процедурный пиксель-арт `UiKitGenerator` (Спринт 13); унификация через 3D-рендер в Blender — отложенный арт-полиш
- UI: дизайн-система `UiTheme` (`Resources/UiTheme.asset`), шрифты Russo One + Rubik (OFL, с кириллицей), процедурный 9-slice кит `Assets/_UI/Kit/`
- Цель: 60 FPS на устройствах 2022+ года

## Дополнительные заметки для ИИ

* **Сингплеер only.** Никакого сетевого кода, никаких NetworkBehaviour, никаких серверных проверок.
* **Адаптивная ориентация (Решение №8).** Портрет (`9:16`, `9:19.5–9:21`) — основной режим на телефонах, ландшафт — для Web и планшетов (`OrientationPolicy`, `LayoutModeService`, `AdaptiveCanvasScaler`, `SafeAreaFitter`).
* **Производительность — приоритет.** Целевой FPS: 60. Zero-GC в `Update`/`FixedUpdate`, object pooling для врагов, снарядов, XP, монет и чисел урона. Профилировать на реальных устройствах, не только в редакторе.
* **Камера** — top-down 45°, следует за героем. Арена больше видимой области.
* **Data-Driven.** Не хардкодить размеры и балансные значения — `ScriptableObject` для героев, врагов, способностей, карточек, волн, апгрейдов, талантов и общих конфигов (`RunRulesConfig`, `ComboConfig`, `PickupConfig`, `SecretConfig`, `CardCatalog` регистрируются в `GameLifetimeScope`).
* **Разделять логику и визуал.** Визуальная модель — child-объект `Visuals`, логика не зависит от конкретного меша.
* **Соблюдать зафиксированные дизайн-решения** (раздел «Соглашения»): без `maxLevel`, синергии без стат-пачек и без карточек, без колец под элитами.
* **Новые воксельные модели** — с `.blend`-исходником в `ArtSources/Blender/` и `.obj` с shared-материалами `enableInstancing: 1`.
* **Save-совместимость не нужна** — игра не выпущена, старые сейвы не мигрируем.
* **Unity CLI:** В проекте доступен инструмент `unity command` (CLI). Если стандартных MCP инструментов не хватает, используй `run_command` с вызовом `unity command <tool_name>` в консоли для тяжелых или редких операций (`build`, `bake_navmesh`, `run_tests`).
* **Обязательная компиляция (Ctrl+R):** После ЛЮБОГО изменения C# кода всегда вызывай `UnityEditor.AssetDatabase.Refresh();` (через MCP инструмент `eval`), чтобы скрипты перекомпилировались и работали в Unity.
